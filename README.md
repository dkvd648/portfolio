# Dhanush Dabbiru - Portfolio Website

Personal portfolio website showcasing AI/ML engineering projects, resume, and work samples.

## 🚀 Free Deployment Options

### Option 1: Netlify (Recommended - Easiest!)

**Steps:**
1. Go to [netlify.com](https://netlify.com) and sign up (free)
2. Drag and drop your entire website folder onto Netlify's dashboard
3. Your site is live instantly! You'll get a URL like `yourname.netlify.app`
4. (Optional) Add a custom domain in Settings → Domain management

**Benefits:**
- ✅ Instant deployment
- ✅ Automatic HTTPS
- ✅ Global CDN (fast worldwide)
- ✅ Unlimited bandwidth for personal sites
- ✅ Easy updates (just drag & drop again)

---

### Option 2: GitHub Pages

**Steps:**
1. Create a GitHub account at [github.com](https://github.com)
2. Create a new repository named `yourname.github.io` (replace "yourname" with your GitHub username)
3. Upload all your files to this repository
4. Go to Settings → Pages → Source → Select `main` branch
5. Your site will be live at `https://yourname.github.io`

**Benefits:**
- ✅ Free custom domain support (yourdomain.com)
- ✅ Version control included
- ✅ Professional developers use it

---

### Option 3: Vercel

**Steps:**
1. Go to [vercel.com](https://vercel.com) and sign up
2. Click "Add New Project"
3. Import from GitHub or drag & drop your files
4. Deploy! You'll get `yourname.vercel.app`

**Benefits:**
- ✅ Lightning-fast deployment
- ✅ Great analytics
- ✅ Automatic HTTPS

---

### Option 4: Cloudflare Pages

**Steps:**
1. Sign up at [pages.cloudflare.com](https://pages.cloudflare.com)
2. Click "Create a project"
3. Upload your files via GitHub or drag & drop
4. Site goes live at `yourproject.pages.dev`

**Benefits:**
- ✅ Cloudflare's super-fast CDN
- ✅ Unlimited bandwidth
- ✅ Great performance
