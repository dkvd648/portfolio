## Sections

- **Skills:** LLM / agents, RAG, computer vision, voice AI, cloud
- **Projects:** selected AI projects with short write-ups

- **Achievements:** AWS AI Practitioner, AWS Cloud Practitioner, Azure AI-900, IEEE and Springer publications
- **Resume:** inline resume plus a downloadable PDF

## Tech

Plain HTML, CSS, and JavaScript with no build step. Responsive grid layout, scroll-reveal animations, and `prefers-reduced-motion` support. Deployed as a static site (`netlify.toml` sets the publish directory, SPA redirect, security headers, and long-lived caching for images, video, and PDF).

## Run locally

```bash
python -m http.server 8080   # then open http://localhost:8080
```
